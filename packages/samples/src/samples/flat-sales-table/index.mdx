This sample renders a flat table with region groups and city leaf rows. It skips the
DataSource and DataModel layers entirely — raw rows are shaped into
`FlattenedDataViewModelParams` in memory and handed to the renderer via
`grid.data = new FlattenedDataViewModel(...)`.

<SampleDemo id="flat-sales-table" height={360} />

## How it works

- The `sales` dataset is loaded through the sample context and grouped by `region`
  with `city` leaf rows, summing `revenue` and `cost` across departments.
- Row hierarchy is encoded with `createRowMeta(depth, isLeaf, isExpanded)` into a
  packed `Uint8Array`.
- The grid uses the `flat` layout (`GroupedRowLayout`), which renders group rows and
  leaf rows from the same single-level row facet.
