Every column in the grid carries its own display settings: how wide it is, how
tall its rows are, and how each cell draws. These live in a per-column **track
definition** (`vTrackDefs`). A column's header is configured separately, as part
of `facetDefs`, which can describe several facet layers in a single definition.

A **facet** is just the grid's word for a header - the two are interchangeable.
We use the generic term because facets aren't only drawn across the top: in a
pivot they also run down the side to label rows. So `facetDefs` covers both.

```ts
grid.data = new FlattenedDataViewModel({
  ...
  options: {
    // one entry per column: width, row height, and how each cell draws
    vTrackDefs: [{ colSize, cellHeight, renderer }, /* ...one per column */],
    // header content (icons, badges) is configured here, not on the column
    facetDefs: { row: [], col: [{ text: "", trackRenderer }], axis: "col" },
  },
});
```

## Column size

A column can fit its widest cell, take a static track width, or size to content
within a min/max clamp - all set through `colSize`.

```ts
// fit to the widest cell
{ strategy: "max-cell" }

// content-sized, but clamped - cap how wide it grows, or give it a floor
{ strategy: "clamped-width", maxWidthInPx: 160 }
{ strategy: "clamped-width", minWidthInPx: 240 }

// a static track width - `unit` is "px", "fr", or "%"
{ strategy: "static", width: 1, unit: "fr" }
```

at 160px and holds Base Salary to at least 240px, while the rest fit content.

## Cell height

`cellHeight` sets the row height for a column in pixels. Give every column the
same height to make the whole table more compact or more spacious.

```ts
vTrackDefs: columns.map(() => ({ cellHeight: 32 })),
```

## Header content

A header renderer can flank the column label with extra content: a marker on the
left and a badge on the right, with the label in the middle. This is a property
of the header, not of the column's cells.

```ts
facetDefs: {
  row: [],
  col: [{
    text: "",
    trackRenderer: (label) => ({
      left: marker(),        // shown before the label
      content: label,        // the label itself
      right: kindBadge(),    // shown after the label
    }),
  }],
  axis: "col",
},
```

Try it below: each header shows a leading marker and a trailing badge naming the
kind of data in the column.

## Cell renderer

A cell renderer takes over how a column's values are drawn. It returns text or
DOM for a single cell - so a column can render a bar, a pill, or anything else
instead of plain text. Unlike a header renderer, a cell has no left/right slots;
the renderer lays out the whole cell itself.

```ts
const salaryBar = (value, _dataCtx, ctx) => {
  ctx.container.style.display = "flex";
  // ...build a bar sized to the value, plus an amount label
  return [track, label];
};

vTrackDefs: columns.map((column) => ({
  renderer: column.field === "base_salary" ? salaryBar : undefined,
})),
```

Try it below: the Base Salary column draws each value as a proportional bar
while the other columns stay as text.
