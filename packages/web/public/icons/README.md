# Icons

Static icon assets served at `/icons/...`.

- PNG icons: drop files directly in this folder (e.g. `sales.png` → `/icons/sales.png`).
  Reference in markup as `<img src="/icons/sales.png" alt="" />`.
  Prefer @2x resolution (e.g. a 48px icon exported at 96px) for crisp rendering.
- SVG icons: instructions pending.

Files here are copied verbatim into the static export by `next build`.
