---
title: Installation
description: Install SuperPlot with your coding agent in three steps - open an agent, paste the setup prompt, and converse to build your grid.
---

SuperPlot is built to be set up by your coding agent. Point it at our setup skill, and it installs and wires up the grid for you. Three steps and you are up and running.

<Steps>

<Step>

### Open your preferred coding agent

SuperPlot is agent-agnostic - use whichever coding agent you already work in (Claude Code, Codex, Cursor, Copilot, Gemini, and more). The setup instructions read the same to all of them.

</Step>

<Step>

### Paste the following prompt

Our setup skill will guide your agent to set up SuperPlot for you. Copy the following prompt and paste it in your agent.

```text
I want to set up @superplot/grid. Read https://superplot.dev/grid/setup-skill.md and follow its instructions.
```

</Step>

<Step>

### Converse with your agent to create a grid

Our skill prompts your agent to ask you the right questions before it starts building, so don't worry if you don't have everything up front. Here is an example to start from.

```text
Create a standard grid to show all the data, i should be able to sort the columns and filter by string.
```

</Step>

</Steps>
