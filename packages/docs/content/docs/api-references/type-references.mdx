## AxisExpr

```ts
type AxisExpr =
  | string
  | { type: "cross"; children: AxisExpr[] }
  | { type: "concat"; children: AxisExpr[] }
  | { type: "hierarchy"; fields: string[] };
```

A plain string is a column name. `cross`, `concat`, and `hierarchy` are table algebra operators used to compose pivot axes. See [PivotTableDataModel](/docs/datamodel/pivot-table-datamodel#table-algebra-operators) for usage and visual examples.

## AxisConfig

```ts
type AxisConfig = { expr: AxisExpr; projection?: DimensionalProjectionPath[] };
```

Wraps an `AxisExpr` with optional [dimensional projection](/docs/datamodel/pivot-table-datamodel#dimensional-projection) to control which values are expanded.

### FacetData

```ts
type FacetData = (string | null)[][];
```

An array of facet levels. Each level is an array of values across all columns (for column facets) or all rows (for row facets). `null` means the value is the same as the previous cell at that level (used for merge/span rendering).

### LayoutEvents

Events emitted by the layout engine and forwarded through the [Grid](/docs/renderer) instance.

```ts
type LayoutEvents = {
  renderComplete: { x0: number; y0: number; x1: number; y1: number };
  viewDataEmpty: { startRow: number; endRow: number };
  viewModelDataChanged: { x0: number; y0: number; x1: number; y1: number };
  "debug_perf:metrics": {
    timeToRender: number;
    renderCount: number;
    nodesActive: number;
    nodesAppendedInThisFrame: number;
    nodesDeletedInThisFrame: number;
    contentCellRerenderCount: number;
    poolSize: number;
  };
};
```

### GridEvents

Extends [LayoutEvents](#layoutevents) with selection events. This is the event map for the `Grid` class.

```ts
type GridEvents = LayoutEvents & {
  selectionAdded: { hash: string; fromRow: number; fromCol: number; toRow: number; toCol: number };
  selectionRemoved: { hash: string; fromRow: number; fromCol: number; toRow: number; toCol: number };
};
```

### PredicateNode

```ts
type PredicateNode =
  | { type: "facet"; predicate: FacetPredicate }
  | { type: "cell"; predicate: CellPredicate };
```

### FacetPredicate

```ts
type FacetPredicate = (dim: string, dimVal: string | null, path: [string, string | null][]) => boolean;
```

A function that tests whether a facet cell matches. `dim` is the dimension name, `dimVal` is the cell's value, and `path` is the ancestor facet values as `[dimName, dimValue]` pairs.

### CellPredicate

```ts
type CellPredicate = (value: any) => boolean;
```

A function that tests whether a data cell's value matches.

### TerminalOp

```ts
type TerminalOp =

  | { type: "style"; fn: (container: HTMLElement) => void };
```
