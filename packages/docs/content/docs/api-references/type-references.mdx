## AxisExpr

```ts
type AxisExpr =
  | string
  | { type: "cross"; children: AxisExpr[] }
  | { type: "concat"; children: AxisExpr[] }
  | { type: "hierarchy"; fields: string[] };
```

A plain string is a column name. `cross`, `concat`, and `hierarchy` are table algebra operators used to compose pivot axes. See [PivotTableDataModel](/docs/datamodel/pivot-table-datamodel#table-algebra-operators) for usage and visual examples.

## AxisConfig

```ts
type AxisConfig = { expr: AxisExpr; projection?: DimensionalProjectionPath[] };
```

Wraps an `AxisExpr` with optional [dimensional projection](/docs/datamodel/pivot-table-datamodel#dimensional-projection) to control which values are expanded.
